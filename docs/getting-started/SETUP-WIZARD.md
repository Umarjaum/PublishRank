# Setup Wizard

The wizard confirms the publication foundation: publication identity, publisher logo, default social image, sitemap coverage and News SEO choices.

## Opening it

- Sidebar: **PublishRank → Setup Wizard** (under Dashboard), and **Help → Setup wizard** in the PublishRank side menu
- Dashboard hero button and the first workflow card
- Plugins screen row link and the toolbar shortcut
- Dashboard checks such as *Publisher logo* link straight to the relevant wizard step

Until setup is complete the sidebar entry reads **Complete Setup →**; afterwards it reads **Setup Wizard** and can be reopened at any time to edit values (`&edit=1&step=N`).

## Layout

The wizard uses the same frame as Features, General Settings and Sitemap Hub: the branded header, the PublishRank side menu and the wizard in the main column.

- **Step track**: one dot per step. The line fills up to the current step; finished steps are links. On phones only the dots show, with "Step N of 8" and the step name above them.
- **Action bar**: stays at the bottom of the screen and shows whether the step has unsaved changes. **Save & continue** saves and moves on, **Back** saves and goes back, **Skip for now** (optional steps only) moves on without saving, **Exit wizard** leaves without finishing. Pressing Enter in a field is the same as Save & continue.
- **Unsaved changes**: leaving a step through the menu, the step track, Skip or Exit asks for confirmation first.
- **Review**: the last step shows one tile per area with an Edit button that opens the right step. The same tiles appear on the completed screen.

## First run (locked)

On a fresh install every other PublishRank screen opens the wizard until the required publisher fields are saved. During that time the side menu shows the other screens with a lock icon instead of links.

## Access

Administrators always have access. The separate setup capability can be delegated to editors under Newsroom roles.
