# Installation

1. Upload the `publishrank` folder to `/wp-content/plugins/`, or install the ZIP through **Plugins → Add New → Upload Plugin**.
2. Activate **PublishRank**.
3. Open **PublishRank** in the admin sidebar. **Setup Wizard** is listed directly under **Dashboard**.
4. Review titles, schema, sitemap and robots settings before using the plugin on a production site.
5. Open your sitemap index in a browser and submit that one address in Google Search Console and Bing Webmaster Tools.

Requirements: WordPress 6.3+ and PHP 7.4+. Official website and support: <https://publishrankseo.vercel.app/>.

PublishRank does not guarantee rankings, crawling, indexing, traffic or inclusion in Google News.
