# PublishRank 2.9.73 — lossless image optimization

## Summary

This maintenance release losslessly recompresses four larger images shipped with PublishRank. Existing filenames, formats, dimensions, color modes, decoded pixels, transparency, animation frame count, timing, and looping are preserved.

## Image changes

- `assets/images/publishrank-banner-publisher.png`: 1,363,475 → 1,264,399 bytes (99,076 bytes saved).
- `assets/images/social-share-1200x630.png`: 154,943 → 146,849 bytes (8,094 bytes saved).
- `assets/icon-128x128.gif`: 149,331 → 142,617 bytes (6,714 bytes saved).
- `assets/icon-256x256.gif`: 405,103 → 384,011 bytes (21,092 bytes saved).

Across all 20 shipped PNG/GIF files, raw image bytes decreased from 4,083,704 to 3,948,728: **134,976 bytes saved (3.31%)**. The two GIFs retain 24 frames, the original 80 ms per-frame timing, and infinite looping. The other 16 PNGs already had no smaller encoding under lossless PNG recompression, so they were left byte-for-byte unchanged.

The bundled runtime directory `assets/vendor/fontawesome-free-7.3.1` contains CSS and font files, not images. Composer’s development-only `vendor/` directory has two PHPUnit report SVG icons totaling 538 bytes; they were left unchanged as tiny third-party files and are excluded from the WordPress submission ZIP.

## Validation

All **32 standalone PHP regression tests** passed. PHP lint passed for production, bootstrap, and test files; `node --check` passed for JavaScript assets; and `git diff --check` passed. Composer PHPCS reported **0 errors** and **177 existing warnings**.

The four recompressed files were compared against their original tracked copies: PNG dimensions, modes, ICC/transparency metadata, and decoded pixel bytes match; GIF dimensions, frame count, loop, per-frame duration, and every composited RGBA frame match. No image was resized, cropped, recolored, converted to another format, or replaced with a remote asset.

The WordPress.org ZIP is generated by `tools/build_plugin_zip.py`; it excludes Composer development dependencies and test/docs/tooling files.
