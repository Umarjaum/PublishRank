# PublishRank asset sources

The files in `src/assets/js/` and `src/assets/css/` are the reviewable source copies for the runtime assets in `assets/js/` and `assets/css/`. PublishRank currently ships these assets without a build step; if a future release minifies or bundles them, the build command and generated-file mapping will be documented here.

The maintained source repository is https://github.com/Umarjaum/PublishRank.
